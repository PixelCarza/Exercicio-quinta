Curso de Desenvolvimento de Software Multiplataforma

Bem-vindo ao portal da disciplina de Desenvolvimento Web I da Fatec Araras. Utilize este ambiente para consultar informações sobre o curso e horários.

Objetivos e Competências do Curso

  • Elaboração de páginas web responsivas utilizando HTML5 e CSS3
  • Utilização do CSS Grid Layout e Flexbox para diagramação avançada
  • Desenvolvimento interativo utilizando JavaScript e manipulando o Dom
  • Uso de ferramentas de controle (Git e GitHub).
